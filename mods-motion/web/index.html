pixelbar

A pixel-art status strip for Claude Code, and a three-minute look at how a mod draws it.

    Install

    /plugin marketplace add zeckon/claude-plugins
    /plugin install pixelbar@zeckon-claude-plugins

    Needs a Claude Code build with the mods API (tested on 2.1.308). The strip appears under the prompt right away.

    In the video

    What each tile on the strip means, the walker's five moods, sections and 12 palettes, then how a mod works: hooks, events, state, and the cell grid that becomes the strip.

    Source: claude-mod-presentation (the video) and claude-plugins (the mod). Press space to play or pause.
